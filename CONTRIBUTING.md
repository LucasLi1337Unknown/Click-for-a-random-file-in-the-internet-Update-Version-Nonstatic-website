# Contributing

Thanks for wanting to improve Random Internet File.

## How to contribute

1. Fork this repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test the website locally.
5. Open a pull request explaining what you changed.

## Guidelines

- Keep the project usable on GitHub Pages.
- Do not add code that automatically downloads executable or high-risk files.
- Do not add malware, credential stealers, trackers, or deceptive downloads.
- Keep the random-file feature focused on public files.
- Avoid breaking the one-click download flow.
- Keep frontend code readable and dependency-light.

## Good contribution ideas

- Better filtering
- Faster public-file discovery
- More safe file formats
- UI improvements
- Accessibility improvements
- Better error handling
- More reliable backend support
