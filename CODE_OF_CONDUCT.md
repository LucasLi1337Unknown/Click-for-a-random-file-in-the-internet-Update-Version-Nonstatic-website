# Code of Conduct

## Our pledge

We want this project to be welcoming, useful, and respectful to everyone.

## Expected behavior

Be respectful, give constructive feedback, and focus discussion on improving the project.

## Unacceptable behavior

Harassment, threats, discrimination, doxxing, spam, malicious code, or intentionally deceptive contributions are not acceptable.

## Enforcement

Project maintainers may remove comments, issues, pull requests, or contributors that violate these rules.
