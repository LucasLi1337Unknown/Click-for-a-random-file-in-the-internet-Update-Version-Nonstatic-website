# Security Policy

## Reporting a vulnerability

If you find a security problem, please avoid posting exploit details publicly before a fix is available.

Open a GitHub issue with a minimal description if the issue is not sensitive. For sensitive vulnerabilities, contact the repository owner privately through an available GitHub contact method.

## Scope

This project intentionally blocks executable, script, installer, disk-image, and archive file types from automatic random downloading.

Please report issues involving:

- bypasses of the blocked file-type rules
- unsafe redirects
- server-side request forgery in the Worker
- arbitrary proxying to non-Internet-Archive hosts
- download spoofing
- cross-site scripting
